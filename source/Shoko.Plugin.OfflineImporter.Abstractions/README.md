# Shoko Offline Importer Abstractions

The contracts another [Shoko Server](https://github.com/ShokoAnime/ShokoServer) plugin uses to run the
[Offline Importer](https://github.com/ShokoAnime/Shoko.Plugin.OfflineImporter)'s file name matching, auto-match
rules and release group lookup. It carries none of the plugin itself, and is released together with it, under the
same version.

See [the documentation](https://github.com/ShokoAnime/Shoko.Plugin.OfflineImporter/blob/stable/docs/abstractions.md)
for the services, the ID tag grammar and how to reference the package from your plugin.
